# Tic-Tac-Toe-Minimax-AI
This is a tic tac toe AI using minimax algorithm to tell who is winning.

Its working per situation is: 
1. Making a move on a board
2. Putting it in opponents shoes
3. Playing a move by oppenent
4. Doing it until someone wins or loses, or it is a tie

It does this for every possible move on the board

**Note:** The AI takes a 2D array as input, `X` in the array for X, `O` for O, `-` for no move done on the box
`[["X", "-", "O"], ["X", "X", "-"], ["O", "-", "-"]]` ✔️
`[["x", "", "o"], ["x", "x", ""], ["o", "", ""]],` ❗
